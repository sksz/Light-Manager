this way** — that is the [source document](../../architecture.md). If you want
to develop the application rather than just use it →
[the guide](../guide/README.md).

## The three shortest routes

- **First time ever** → [1](01-what-is-it.md) → [2](02-installation.md) →
  [7](07-scenarios.md), the first scenario.
- **It is open and I do not know what to press** →
  [3](03-screen-and-controls.md). Inside the application: **`F1`**.
- **Something does not work** → [2](02-installation.md), "When something does
  not work".

## Where the lists in this manual come from

The lists of keys, modules and settings **are not copied from memory** — they
come from the same declarations in the code that the status bar and the `F1`
window are built from. From step 66 the quality gate keeps them honest: a key
changed in the code without a correction in the manual turns the gate red.
