# Documentation in English

Three documents, each for a different reader. **Polish is the source language**
— content changes start in [../pl/](../pl/README.md) and this tree is their
translation. An English page that has fallen behind its Polish original is
a defect the quality gate reports, not a normal state.

| Document | For whom | Answers the question |
|---|---|---|
| [Manual](manual/) | someone who uses the application | how do I use this |
| [Guide](guide/) | someone who develops it | how do I add my own thing |
| [Onboarding](onboarding/) | someone on their first day here | where do I start |

Rules and the reasoning behind them live outside this tree — in the
[source document](../architecture.md); why something turned out the way it did —
in the [decision log](../plans/00-decyzje.md). Both are Polish-only on purpose:
they are documents about **working on** the project, not documents **of** the
project. Boundaries of every kind: [documentation map](../README.md).
