# Podręcznik użytkownika

Odpowiada na pytanie **jak tego użyć**. Nie odpowiada na pytanie **dlaczego tak
działa** — to jest [dokument źródłowy](../../architecture.md). Chcesz aplikację
rozwijać, a nie tylko jej używać → [przewodnik](../przewodnik/README.md).

## Trzy najkrótsze drogi

- **Pierwszy raz w życiu** → [1](01-czym-to-jest.md) → [2](02-instalacja.md) →
  [7](07-scenariusze.md), scenariusz pierwszy.
- **Aplikacja stoi otwarta, nie wiem, co nacisnąć** →
  [3](03-ekran-i-sterowanie.md). W samej aplikacji: **`F1`**.
- **Coś nie działa** → [2](02-instalacja.md), sekcja „Gdy coś nie działa".

## Skąd biorą się spisy w tym podręczniku

Spisy klawiszy, modułów i ustawień **nie są przepisane z pamięci** — pochodzą
z tych samych deklaracji w kodzie, z których powstaje pasek stanu i okno `F1`.
Od kroku 66 pilnują tego testy bramki jakości: klawisz zmieniony w kodzie bez
poprawki w podręczniku czerwieni bramkę.
