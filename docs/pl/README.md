# Dokumentacja po polsku

Trzy dokumenty, każdy dla innego czytelnika. **Polski jest językiem źródłowym**
— zmiana treści zaczyna się tutaj, a wersja angielska
([../en/](../en/README.md)) jest jej tłumaczeniem.

| Dokument | Dla kogo | Odpowiada na pytanie |
|---|---|---|
| [Podręcznik](podrecznik/) | ten, kto aplikacji używa | jak tego użyć |
| [Przewodnik](przewodnik/) | ten, kto ją rozwija | jak dołożyć swoją rzecz |
| [Onboarding](onboarding/) | ten, kto jest tu pierwszy dzień | od czego zacząć |

Reguły i ich uzasadnienia stoją poza tym drzewem — w
[dokumencie źródłowym](../architecture.md); dlaczego coś wyszło tak, a nie
inaczej — w [dzienniku decyzji](../plans/00-decyzje.md). Granice wszystkich
rodzajów: [mapa dokumentacji](../README.md).
